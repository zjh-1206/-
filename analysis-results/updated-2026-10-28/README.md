## 数据解释

- 温度单位°C，初始氟含量单位%，相比方向未注明；响应2按截图称“磷萃取率/%”，优化时仍按此前目标将其作为磷损失最小化；β无量纲。
- 直接拟合用户确认的截图响应，不使用旧版浓度和体积反推；保留截图β值，仅进行舍入一致性检查。更正后的完整精度测量工作簿未提供，末位结果可能与软件内部全精度值略有差别。
- 统计改善来自数据版本变化，不能归因于模型简化。17次实验全部保留，没有删点或修改截图显示值。
- 预测R²经显式逐次留一重拟合核验，属于内部验证，不能替代新增独立实验。

按氟回收最大化、磷萃取最小化的等权期望度，在BBD设计点凸包内的取整候选为 **95°C、相比0.992、初始氟含量1.195%**；模型预测氟萃取率约85.98%、磷萃取率约4.90%。仅供验证，尚未证明优于现有工况。
