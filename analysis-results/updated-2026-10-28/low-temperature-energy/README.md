# 能耗与萃取效率：低温候选比较

用户要求：**氟萃取率至少80%，磷损失最多5%**。暂无耗电数据，先比较75–95°C原设计范围内的低温方案。没有计算或估算kWh；最低温度不等于实际单位能耗最低。

## 优先比较的验证方案

|候选|温度|相比|初始氟含量|氟萃取率预测|磷损失预测|
|---|---:|---:|---:|---:|---:|
|A：低温验证|75°C|0.830|1.000%|80.98%|3.99%|
|B：保守验证|90°C|0.770|1.000%|81.21%|2.92%|

A的模型均值区间满足阈值，但单次95%预测区间跨出要求：F约79.82–82.15%，P约1.96–6.03%。B的单次模型预测区间仍在要求内：F约80.11–82.30%，P约0.94–4.90%。均为未验证候选，不是质量保证。

若仅按点预测或平均响应CI界筛选，最低温可到75°C；按单次95%PI界筛选的数值最低温度约87.04°C。87.1°C取整候选余量极小，因此90°C易操作点更适合用作验证对照。完整候选和区间见Excel。

## 下一步实测

A/B各至少3次独立全流程重复；记录本批F/P、总耗电、进料体积、起始温度、处理时间及搅拌设置。模板中的未来实测栏均为空，不能用旧响应直接配新批次能耗。

实际比较采用同一计量边界下的kWh/m³进料，以及kWh/kg回收氟。相比改变会影响相体积和热负荷；初始氟相同，也应统一处理量、保温/萃取时长，并记录两相实际体积及相比方向。各响应95%区间未计入选模、寻优、系统误差和截图舍入，实际是否达标及是否节能均需试验确认。
